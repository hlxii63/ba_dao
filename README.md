# 拔刀 · 网页版

单文件游戏：**`拔刀.html`**（`dist/拔刀.html` 是同一份备份）。双击就能玩，不需要安装、不需要后端服务器。

## 怎么玩

1. 打开 `拔刀.html` → 填昵称 → **创建房间** → 把 4 位房间号发给朋友（朋友打开同一个网页 → 填房间号 → 加入）
2. 人不够？房主可以点 **＋ 电脑玩家**，一个人也能开局
3. **所有人（含房主）都点「准备好了」**，房主才能点开始（电脑玩家自动算准备好）
4. 每回合所有人同时挑道具、点头像选目标 → 点 **锁定出招**；x 秒后一起结算，y 秒后进下一回合
5. **时间到了还没锁定，就自动按「集」结算**（白拿 1 点，但集不提供防御）
6. 打完一局点「再来一局」会回到房间，**所有人要重新确认一遍**

默认节奏 **选择 5 秒 / 展示 5 秒**，房主可改（按"一回合只挑一种道具"设计，5 秒足够定决策）。

房主在房间里能切这几个开关：**选择/展示时间**、**全员锁定后立刻结算**、**点数公开（明牌局）**、
以及三个拓展包（血量 / 彩虹斩叠加 / 自守）。

## 规则（实现口径）

核心：每回合只挑**一种**道具；`受到的伤害 = 外面所有人打你的总攻击 − 你的防御`；
血量初始 0、下限 0，**只要 血量 − 伤害 < 0 就死**（0 血时挨 1 点就死，合掌加的血就是缓冲）。
攻击 / 防御 / 反盾回合末清零，血量 / 点数 / 赠品留到下一回合。点数不会自动增长，只能靠「集」。

### 叠与不叠

- **不可叠**（默认）：同一种道具对**同一个人一回合只能用一次**。想打多个人就买 N 把同种刀砍 N 个人——一人一刀，不能一人三刀。
- **可叠**（只有原规则明确写过的这三样）：精血「可叠加」、彩虹斩（开了叠加包后 n 倍）、偷「不论使用数量」。
- **不可叠**（其余全部，含肥美 / 剑气 / 天雷 / 叠肥）：同一种道具对**同一个人一回合只能用一次**，一人一刀、不能一人三刀。
- **叠肥是独立道具**：吃掉 3 个肥美、造成 2-ε 伤害（不是"把肥美叠起来"）。
- 可叠道具分给多人时**必须完全均分**：5 个精血不能 3+2，要么全砸一个人，要么凑成 4/6 个。

### 开局前拍板的规则歧义（都按下面口径实现）

| # | 问题 | 采用口径 |
|---|------|---------|
| 1 | 血量模型 | 初始 0 / 下限 0；伤害 > 血量即死 |
| 2 | 点数增长 | 初始 0，不自动增长，只靠「集」 |
| 2b | 攻击自带防御 | **攻击 x 点就自带 x 点防御**（原规则里"减你的防御**或攻击**"就是这个意思）：互砍一刀双方都活，不会平局 |
| 3 | 胜负 | 无回合上限，活到最后者赢；全灭平局 |
| 4 | 反盾被破 | 反盾者无视血量暴毙，攻击方不死、不反伤 |
| 5 | 拓展包 | 默认全关，房主可勾选（血量 / 彩虹斩叠加 / 自守） |
| 6 | 「偷」消耗 | 0 点（原文未写）；用偷的回合防御锁 0.5 |
| 7 | 彩虹斩 vs 防御 | 先算 `总攻击 − 防御`，≤0 被挡下（白洞能挡），>0 命中即死、无视自守 |
| 8 | 赠品 | 回合末进背包，可跨回合累积，需主动选用 |
| 9 | 死亡后 | 点数与赠品清空，人变观战者，**头像变黑白** |
| 10 | 破盾消耗 | 1 点（原文未写）；被防住没扣血就不触发清空 |
| 11 | 多目标 | 点头像多选，买 N 把同种刀砍 N 个人；有「全选」（按点数封顶） |
| 12 | 一回合几种道具 | **只能一种**：选了集就不能出刀，选了小防就不能砍人 |
| 13 | 超时没锁定 | **自动出「集」**；主动点「清空 + 锁定」则是真的空手（有时你就不想被偷） |
| 14 | 可叠道具分摊 | 多目标必须整除，界面上加减数量按「每人一份」走，天然均分 |
| 15 | 开局 | 所有玩家（含房主）点「准备好了」才能开始；电脑自动算准备好 |
| 16 | 再来一局 | 回到房间页，准备状态清空，要重新确认 |
| 17 | 房主移人 | 房间页可以移出任何人（含电脑玩家）；对局中不提供移出 |
| 18 | 自守决斗 | 4n+1 回合内让每个致死者「死过一遍」（把对方自守打出来也算）即复活，超时真死；双方都不能再开自守 |
| 19 | 出招阶段的信息 | 别人的**点数 / 背包**不下发到客户端（显示 `?`），杜绝"靠点数消耗反推对手出招" |
| 19b | 「点数公开」开关 | 默认关＝**全流程**都看不到别人的点数（含结算展示、战报花费、日志数额）；开了才是明牌局 |
| 20 | 「偷」的多选 | 点头像选中、再点取消；同一个对象不能重复选；最后一个目标取消不掉（想全取消就再点一次卡片） |
| 20b | 「偷」的结算顺序 | **逐个对象独立结算**：出「集」的人点数照偷（不管别人出什么）；只要对象里有**一个人**出防/反盾/自守/合掌，小偷必死（偷到的点数随死亡清空） |
| 21 | 超时与「清空」 | 超时没锁定＝自动「集」；主动点「清空」只是清草稿（已经锁定过才会把"空手"提交上去） |
| 22 | 点数是否公开 | 房主开关，**默认关**：出招阶段别人的点数/背包显示 `?`（防反推），偷人靠猜；开了就是明牌局 |

另外两点实现说明：所有攻击同时结算（被反盾弹死的人，本回合的刀照样生效）；伤害公式只减「防御」，「反盾」单独判定。

想改数值：搜索 `破盾` 或 `偷`，道具表在文件开头的 `ITEM_LIST` 里，`cost` 一项就是点数消耗。想改可叠名单：搜 `STACKABLE`。

## 视觉与反馈

- **结算是一场"逐拍演出"**：顶部字幕条先念出当前这一步（"阿飞 ⚔ 一刀×1 → 老王 −1"），然后**道具真的飞过去**：
  - **双刀就是两把刀子**从你卡上飞向目标（四刀＝4 把、五刀＝5 把、彩虹斩＝🌈、磁暴＝🧲、偷＝🫳 的手），落在对方身上
  - 对方出了**防具** → 他身上顶出一个**蓝色盾牌**把刀挡下
  - 对方出了**反盾** → 换成**橙色盾牌**，把飞来的刀子**原样弹回**攻击者
  - 挨打的人卡片抖一下、飘出伤害数字；死亡打 💀
  - 几何动画用的是 `offset-path` 真实路径（浏览器不支持时自动退回连线），画完停留一会儿再淡出，不会一屏全是线
- **求和写明白**：挨打的人卡片上有一行 `🧮 老王 1 + 小美 1 = 2 点 − 防御 1（含刀自带 1）= 掉 1 点`，
  一眼看出是"相加"而不是"取最大"
- **完全死亡**（真正出局，不是决斗中）的玩家头像变**黑白**
- **信息不泄露**：默认看不到别人的**点数与背包**（显示 `?`），连结算战报里的"消耗 X 点"和日志里的点数数额都不给；
  房主开了「点数公开」才变成明牌局
- 战斗日志按回合成块，顺序是"谁打谁 → 防御/花费 → 阵亡 → 存活名单"：
  ```
  【第 3 回合】
  ⚔ 老王 用「五刀」打 小美（5 点）
  ⚔ 小美 用「彩虹斩」打 老张（8 点）
  🛡 小美 防御 8（含攻击自带 8） 挡下 5 点
  ☠ 老张 阵亡 —— 被打死（合计 8 点 − 防御 0 = 掉 8 点）
  —— 存活 2 人：老王、小美
  ```
- 动画按展示时长自动压缩节奏，3 秒也能播完；开了系统「减少动态效果」则自动关掉动画

## 已知限制

- 在线联机走 PeerJS 公共信令 + WebRTC，**偶尔会不稳**；公司/校园网若封了 WebRTC 或点对点打洞失败（对称 NAT）会连不上，此时退回「房主 + 电脑玩家」的单机房间照样能玩。
- 房主就是主机，房主退出/刷新，这一局就结束了（没有主机迁移）。
- 用 `file://` 直接双击打开时，部分浏览器对 `file://` 来源的联机有限制；想让联机最稳，把 HTML 丢到任意静态托管（GitHub Pages 等）再打开。
- 掉线的玩家会留在场上当活靶子（自动按「集」结算），房主可以在房间页把他移出。
- 每回合最多 12 人。

## 开发 / 自测

```
node build.js              # 把 src/ 四个文件打包成 拔刀.html（单文件，无外部依赖）
node test/engine.test.js   # 规则引擎 60 条断言（含 8 人 40 回合全电脑压测）
node test/dom.test.js      # jsdom 里模拟 7 个真实玩家把界面点一遍（85 条，含真实计时与几何动画）
./run-tests.sh             # 上面三条一起跑
```

源码分工：`src/engine.js` 规则引擎（纯逻辑、可单测）· `src/view.js` 渲染与交互 · `src/net.js` 联机与计时 · `src/style.css` 样式 · `src/index.html` 模板。
