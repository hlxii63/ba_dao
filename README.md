# 拔刀 · 网页版

单文件游戏：**`拔刀.html`**（`dist/拔刀.html` 是同一份备份）。双击就能玩，不需要安装、不需要后端服务器。

## 怎么玩

1. 打开 `拔刀.html`
2. 填昵称 → **创建房间** → 把 4 位房间号发给朋友（朋友打开同一个网页 → 填房间号 → 加入）
3. 人不够？房主可以点 **＋ 电脑玩家**，一个人也能开局
4. 房主设好「选择时间 x」「展示时间 y」和拓展包开关 → **开始游戏**
5. 每回合所有人同时选道具、点头像选目标 → 点 **锁定出招**；x 秒后一起结算，y 秒后进下一回合

## 规则（实现口径）

核心：`受到的伤害 = 外面所有人打你的总攻击 − 你的防御`；血量初始 0、下限 0，**只要 血量 − 伤害 < 0 就死**（0 血时挨 1 点就死，合掌加的血就是缓冲）。攻击 / 防御 / 反盾回合末清零，血量 / 点数 / 赠品留到下一回合。点数不会自动增长，只能靠「集」，且集点当回合就能花。

开局前需要拍板的 13 处规则歧义（已按下面的口径实现）：

| # | 问题 | 采用口径 |
|---|------|---------|
| 1 | 血量模型 | 初始 0 / 下限 0；伤害 > 血量即死 |
| 2 | 点数增长 | 初始 0，不自动增长，只靠「集」；集点当回合可用 |
| 3 | 胜负 | 无回合上限，活到最后者赢；全灭平局 |
| 4 | 反盾被破 | 反盾者无视血量暴毙，攻击方不死、不反伤 |
| 5 | 拓展包 | 默认全关，房主可勾选（血量 / 彩虹斩叠加 / 自守） |
| 6 | 「偷」消耗 | 0 点（原文未写）；用偷的回合防御锁 0.5，买防具也顶不上 |
| 7 | 彩虹斩 vs 防御 | 先算 `总攻击 − 防御`，≤0 被挡下（白洞能挡），>0 命中即死、无视自守 |
| 8 | 赠品 | 回合末进背包，可跨回合累积，需主动勾选用 |
| 9 | 死亡后 | 点数与赠品清空，人变观战者 |
| 10 | 破盾消耗 | 1 点（原文未写）；被防住没扣血就不触发清空 |
| 11 | 多目标 | 点头像多选，买 n 个选 m 人 → 均分，余数给先选的；有「全选」 |
| 12 | 多次反盾 | 不叠加，取最大弹性范围 |
| 13 | 自守决斗 | 4n+1 回合内让每个致死者「死过一遍」（把对方自守打出来也算）即复活，超时真死；决斗双方都不能开自守 |

另外两点实现说明：所有攻击同时结算（被反盾弹死的人，本回合的刀照样生效）；伤害公式只减「防御」，「反盾」单独判定。

想改数值：搜索 `破盾` 或 `偷`，道具表在文件开头的 `ITEM_LIST` 里，`cost` 一项就是点数消耗。

## 已知限制

- 在线联机走的是 PeerJS 公共信令 + WebRTC，**偶尔会不稳**；公司/校园网若封了 WebRTC 或点对点打洞失败（对称 NAT），会连不上，此时退回「房主 + 电脑玩家」的单机房间照样能玩。
- 房主就是主机，房主退出/刷新，这一局就结束了（没有主机迁移）。
- 用 `file://` 直接双击打开时，部分浏览器对 `file://` 来源的联机有限制；想让联机最稳，把 HTML 丢到任意静态托管（GitHub Pages 等）再打开。
- 掉线的玩家会留在场上当活靶子（会自动算空手），房主可以把他踢掉。
- 每回合最多 12 人。

## 开发 / 自测

```
node build.js              # 把 src/ 四个文件打包成 拔刀.html（单文件，无外部依赖）
node test/engine.test.js   # 规则引擎 43 条断言（含 8 人 40 回合随机压测）
node test/dom.test.js      # jsdom 里模拟 5 个真实玩家把界面点一遍（42 条）
```

源码分工：`src/engine.js` 规则引擎（纯逻辑、可单测）· `src/view.js` 渲染与交互 · `src/net.js` 联机与计时 · `src/style.css` 样式 · `src/index.html` 模板。
